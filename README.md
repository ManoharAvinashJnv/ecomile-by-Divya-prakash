🌱 EcoMiles

EcoMiles is a sustainable transportation tracking platform that encourages people to choose eco-friendly travel options such as walking, cycling, and public transport. Users earn EcoPoints for every green journey, helping promote cleaner cities and healthier lifestyles.

🚀 Features

- 🔐 Google Sign-In
- 📍 Manual & GPS-based trip logging
- 🏆 EcoPoints reward system
- 🌍 CO₂ savings dashboard
- 🎖️ Badges & Leaderboard
- 💰 Conceptual road tax rewards (₹1 per 10 EcoPoints)

🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Google Maps / GPS API

📖 How It Works

1. Sign in using your Google account.
2. Log your trip manually or via GPS.
3. Earn EcoPoints based on your travel mode.
4. Track CO₂ savings and compete on the leaderboard.
5. Redeem points for conceptual road tax benefits.

⚠️ Current Limitations

- GPS verification is not fully implemented.
- Trip data can be entered manually.
- Road tax redemption is a prototype concept.

🔮 Future Improvements

- Automatic travel mode detection
- AI-based fraud detection
- Regional language support
- Enhanced privacy controls
- Government transport database integration
